# Alglinton Amalgamation

A proposed signal timing for Eglinton Avenue West at Allen Road in Toronto, by Eglinton West (Cedarvale) Station, with a live traffic simulation on top of the area map.

The two intersections, Allen Rd S and Allen Rd N, sit about 100 m apart. Under the current timing, the eastbound left onto Allen Rd N only gets green after Allen Rd S has gone red, so only the handful of cars already waiting in the gap get through each cycle. The proposed cycle turns that left arrow green 2 seconds after Allen Rd S goes green eastbound, so the cars coming through Allen Rd S can keep going onto Allen Rd N.

## Pages

- `eglinton-signals-map.html`: signals, crosswalks, cars, buses and pedestrians drawn on the reference map, plus the 120-second timing chart. This is the main page.
- `eglinton-signals.html`: an earlier drawn version that compares the current and proposed timing.

## Recording

On Windows, double-click `record.bat`. It opens the map page in Chrome kiosk mode with a full-screen layout and no browser bars, ready for screen recording. Space pauses, 1/2/4/8 sets the speed, and Alt+F4 closes it.

Traffic volumes are made up to show the pattern. They weren't counted on site.
